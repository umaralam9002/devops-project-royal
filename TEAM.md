# Team Responsibilities

## 1. M. Umar Alam — Repository Owner
- Create and maintain the project repository.
- Manage branches and pull requests.
- Coordinate project activities and documentation.
- Ensure all changes follow the protected-branch workflow.

## 2. Team Member 2 — Development and Testing
- Implement assigned project features.
- Test changes before submitting pull requests.
- Identify and fix bugs.
- Review code and provide constructive feedback on teammates' pull requests.

## 3. Team Member 3 — Documentation and Quality Assurance
- Maintain project documentation and the README.
- Verify project functionality and test results.
- Review pull requests and check changes for quality.
- Help resolve review comments and maintain coding standards.

## Code Review Policy
- Respond to review requests within one working day.
- Submit all changes through pull requests.
- Address review comments before merging.
- Do not push directly to the protected `main` branch.
